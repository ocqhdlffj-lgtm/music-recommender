# 오늘의 음악 (음악 추천기)

기분·상황·장르·시대를 고르면 13,423곡 중에서 어울리는 곡을 추천하는 **단일 HTML 파일** 프로젝트입니다.

**바로 열기(공개, 아이폰 사파리 가능): https://ocqhdlffj-lgtm.github.io/music-recommender/**

아이폰은 사파리에서 열고 공유 → '홈 화면에 추가'하면 앱처럼 쓸 수 있습니다. 받은 HTML 파일은 아이폰 '파일' 앱에서 미리보기로만 열려 동작하지 않습니다.

Claude 비공개 링크: https://claude.ai/artifact/KNDPE3bwKZpZTy78Yzstty

PC에서는 `music-recommender.html`을 더블클릭하면 브라우저에서 열립니다. 외부 API는 쓰지 않습니다.

설계·데이터 출처·한계·작업 방법은 `음악추천기-인수인계.md`에 정리돼 있습니다.

## 구조
```
data/songs.txt       직접 고른 203곡 (재즈 66곡 포함) (제목|가수|연도|장르|기분|상황|한 줄 소개)
data/chart_songs.txt 차트 곡 5,586곡 (같은 형식, 소개 칸에 출처)
data/jazz_albums.txt 재즈 명반 수록곡 5,294곡 (소개 칸 = 명반 · 앨범 (연도))
src/template.html    화면·스크립트 템플릿
build.py             위 데이터 + 템플릿 -> music-recommender.html
tests/test_build.py  데이터 검증·빌드 테스트
```

## 사용
```
python build.py                          # music-recommender.html 생성
python build.py --check                  # 데이터 형식만 검증
python -m unittest discover -s tests     # 테스트
```
`music-recommender.html`과 `docs/index.html`(GitHub Pages 사본)은 생성되는 파일입니다. 고친 뒤 `python build.py` → 커밋 → `git push`하면 1~2분 뒤 공개 주소에 반영됩니다. 곡은 `data/songs.txt`에서, 화면은 `src/template.html`에서 고치세요.

## 기능
- 필터: 같은 줄 안에서는 OR, 서로 다른 줄끼리는 AND
- 고른 기분·상황과 많이 겹치는 곡이 위로 정렬
- 🎲 한 곡만 골라줘: 가장 잘 맞는 곡 중 하나를 무작위로 골라 맨 위에 강조
- 곡명·가수 검색, ☆ 즐겨찾기 (이 브라우저의 localStorage에 저장)
- 태그 고치기: 카드에서 기분·상황을 직접 바꾸면 이 브라우저에 저장되고 필터·비슷한 곡에 바로 반영. '고친 태그 복사'로 `제목|가수|기분|상황` 목록을 받아 데이터 파일에 옮길 수 있음
- 즐겨찾기 탭에서 '목록 복사'로 `제목 - 가수 (연도)` 텍스트 복사
- 🕰 그때 그 노래: 태어난 해를 넣고 나이대(10대 초반~30대)를 고르면 그 시절 곡을 연도순으로 보여 줌. 태어난 해는 이 브라우저에만 저장
- 비슷한 곡: 카드의 버튼을 누르면 같은 가수 > 장르·국내외 > 겹치는 기분·상황 > 가까운 연도 순으로 점수를 매겨 최대 300곡을 보여 줌
- 🏆 1위곡 퀴즈: 10문제씩 "처음 1위/차트에 오른 해는?", "다음 중 ○○의 노래는?" (전체 / 한국 1위곡 / 빌보드 중 선택). 최고 기록은 이 브라우저에 저장
- ▶ 듣기: 유튜브 검색 결과로 연결 (영상 링크가 아니라서 깨지지 않음)
- 라이트/다크 테마

## 곡 추가
`data/songs.txt`에 한 줄을 추가한 다음 `python build.py`를 실행합니다.

- 기분: 신남 · 잔잔 · 위로 · 설렘 · 그리움
- 상황: 운동 · 드라이브 · 출근길 · 공부·작업 · 비 오는 날 · 잠들기 전
- 장르: 발라드 · K-pop · 포크 · 인디/밴드 · 록 · 팝 · R&B/소울 · 댄스/일렉트로닉 · 힙합 · 컨트리 · 트로트 · 재즈 · J-pop · 클래식/뉴에이지

화면에서 고친 태그는 '고친 태그 복사' 내용을 `data/tag_edits.txt`에 붙여 넣고 `python build.py`를 실행하면 모든 기기에 반영됩니다.

목록에 없는 값을 쓰면 빌드가 몇 번째 줄인지 알려 주며 멈춥니다. 새 값을 쓰려면 `build.py`의 목록에도 추가하세요.

## 차트 곡 출처
- 빌보드 연말 Hot 100 (1959~2025): 위키백과 각 연도 목록에서 4,587곡. 연도는 처음 차트에 오른 해, 순위는 그중 최고 순위.
- 한국 2010~2025: 위키백과 가온/써클 디지털 차트 주간·월간 1위곡 421곡.
- 한국 1981~2009: 한국어 위키백과의 KBS 가요톱10(1981~1998), MBC 음악캠프(1998~2005), SBS 인기가요(1991~2009) 1위곡 578곡.
- 한국 곡의 제목·가수는 한국어 표기로 맞췄습니다.
- 재즈 명반 수록곡 (5,294곡): 영어 위키백과의 재즈 명반 611장 문서에서 수록곡 목록을 가져옴(보너스·얼터네이트 테이크·라이브 버전 제외, 앨범당 최대 16곡). 연주자·발매 연도는 문서의 앨범 정보 기준. 기분·상황은 앨범 단위로 추정하고 발라드풍 제목은 '잔잔·그리움·잠들기 전'으로 보정
- 직접 고른 곡과 겹치면 직접 고른 쪽이 남습니다.

## 주의
- 차트 곡의 제목·가수·연도·순위는 위키백과 기준이지만, 장르·기분·상황 태그는 작성자가 추정해 붙인 것입니다. 오래되거나 잘 알려지지 않은 곡일수록 정확도가 낮습니다.
- 연도·소개는 작성자의 기억으로 적은 것이라 검수가 필요할 수 있습니다. 연도는 대체로 발매 연도이고, 클래식은 작곡·출판 연도입니다.
- 기분·상황 태그는 주관적입니다.
